# ✅ Как проверить, что парсер работает

## Способ 1: Через Telegram бота

1. **Запустите бота:**
   ```bash
   python run_telegram_bot.py
   ```

2. **В боте нажмите "🔄 Запустить парсер"**

3. **Выберите количество товаров** (например, 3)

4. **Проверьте:**
   - Бот должен написать "✅ Парсер запущен!"
   - Нажмите "📈 Статус" - должно быть "🟢 Статус: Работает"
   - Через несколько минут бот отправит уведомление о завершении

## Способ 2: Через Google Таблицу

1. Откройте таблицу: https://docs.google.com/spreadsheets/d/1VJMixODvnIPBf7EjFoJ8XMH1lepycVlXREKQI7MVxWQ

2. Перейдите на лист "шаблон выгрузуи 1.0"

3. После запуска парсера должны появиться новые строки с данными

## Способ 3: Через логи

1. Запустите парсер через бота

2. В терминале должны появиться логи:
   ```
   Парсер запущен (PID: 12345)
   ```

3. Проверьте папку `logs/summaries/` - должен создаться новый файл `iteration_*.md`

## Способ 4: Проверка процесса

1. Откройте Диспетчер задач (Ctrl+Shift+Esc)

2. Найдите процесс `python.exe` с аргументом `test_parser_engine.py`

3. Если процесс есть - парсер работает

---

## ⚠️ Если парсер не работает

1. **Проверьте логи** в терминале - там будут ошибки

2. **Проверьте Google Sheets:**
   - Файл `config/google-credentials.json` существует?
   - Сервисный аккаунт имеет доступ к таблице?

3. **Проверьте браузер:**
   - Установлен Playwright? (`playwright install chromium`)
   - Есть интернет-соединение?

4. **Проверьте Pipiads:**
   - Аккаунт работает?
   - Данные в `.env` правильные?
