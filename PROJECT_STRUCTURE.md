# 📁 Структура проекта ProductRadar

Полное описание структуры проекта и назначения каждой папки и файла.

---

## 📂 Корневая структура

```
ProductRadar/
├── src/                    # Основной код проекта
├── tests/                  # Тесты и скрипты запуска
├── scripts/                # Вспомогательные скрипты
├── config/                 # Конфигурация и секреты
├── docs/                   # Документация
├── examples/               # Примеры HTML страниц
├── logs/                   # Логи и саммари
├── archive/                # Архивные файлы
├── html_dumps/             # Дампы HTML для анализа
├── screenshots/            # Скриншоты (не в Git)
├── run_telegram_bot.py     # Точка входа для Telegram бота
├── requirements.txt        # Зависимости Python
├── README.md               # Главный README
├── PROJECT_RULES.md        # Правила проекта
└── PROJECT_STRUCTURE.md    # Этот файл
```

---

## 📁 Детальное описание папок

### `src/` — Основной код проекта

**Назначение:** Весь основной код приложения

**Содержимое:**
- `browser_manager.py` — управление браузером (Playwright)
- `parser_engine.py` — парсинг данных с Pipiads
- `sheets_writer.py` — запись данных в Google Sheets
- `telegram_bot.py` — логика Telegram бота
- `config.py` — загрузка конфигурации
- `logger.py` — система логирования
- `validator.py` — валидация данных
- `bot_config.py` — конфигурация Telegram бота
- `summary_manager.py` — управление саммари
- `parser_runner.py` — запуск парсера

**Важно:** Все модули должны быть в этой папке.

---

### `tests/` — Тесты и скрипты запуска

**Назначение:** Тесты и основные скрипты для запуска проекта

**Содержимое:**
- `test_parser_engine.py` — **главный скрипт парсера** (запуск через `python tests/test_parser_engine.py`)
- `test_browser_manager.py` — тест браузера
- `test_google_sheets.py` — тест подключения к Google Sheets
- `test_basic_components.py` — тест базовых компонентов
- `test_copy_last_row.py` — тест копирования строк
- `test_env_reading.py` — тест чтения переменных окружения
- `write_test_to_sheets.py` — тестовая запись в таблицу

**Использование:**
```bash
# Запуск парсера
python tests/test_parser_engine.py

# Проверка подключения
python tests/test_google_sheets.py
```

---

### `scripts/` — Вспомогательные скрипты

**Назначение:** Утилиты и вспомогательные скрипты

**Содержимое:**
- `download_summaries.py` — скачивание саммари с GitHub
- `analyze_html_dump.py` — анализ HTML дампов
- `find_elements_in_html.py` — поиск элементов в HTML

**Использование:**
```bash
# Скачать саммари
python scripts/download_summaries.py
```

---

### `config/` — Конфигурация

**Назначение:** Конфигурационные файлы и секреты

**Содержимое:**
- `.env_sample` — шаблон переменных окружения (в Git)
- `.env` — переменные окружения (⚠️ НЕ в Git!)
- `google-credentials.json` — ключи Google Sheets API (⚠️ НЕ в Git!)
- `cookies.json` — cookies для авторизации (⚠️ НЕ в Git!)
- `README.md` — инструкции по настройке

**Важно:**
- Файлы с секретами НЕ должны попадать в Git
- Используйте `.env_sample` как шаблон
- Подробнее: `docs/guides/SETUP_LOCAL_FILES.md`

---

### `docs/` — Документация

**Назначение:** Вся документация проекта

**Структура:**
```
docs/
├── guides/              # Руководства и инструкции
│   ├── QUICK_START.md
│   ├── QUICK_START_BOT.md
│   ├── TELEGRAM_BOT_SETUP.md
│   ├── SETUP_LOCAL_FILES.md
│   └── ...
│
└── reference/           # Справочники и техническая документация
    ├── TECHNICAL_PLAN.md
    ├── TZ_DETAILED.md
    ├── VIDEO_CARDS_STRUCTURE.md
    ├── ALGORITHM_SUMMARY.md
    └── html_structure_reference.md
```

**Назначение:**
- `guides/` — пошаговые инструкции для пользователей
- `reference/` — техническая документация для разработчиков

---

### `examples/` — Примеры

**Назначение:** Примеры HTML страниц для разработки и тестирования

**Содержимое:**
- `example_of_product_page.html` — пример страницы товара
- `example_adsearch_page.html` — пример страницы ad-search

**Использование:** Для разработки и отладки парсера

---

### `logs/` — Логи и саммари

**Назначение:** Логи работы и саммари итераций

**Структура:**
```
logs/
├── *.log                    # Логи (не в Git)
└── summaries/               # Саммари итераций (в Git)
    └── iteration_*.md
```

**Важно:**
- Логи (`*.log`) не пушатся в Git
- Саммари (`summaries/*.md`) пушатся в Git

---

### `archive/` — Архивные файлы

**Назначение:** Старые файлы, которые больше не используются

**Содержимое:**
- Старые версии документации
- Исторические файлы
- Устаревшие инструкции

**Использование:** Для справки, не используется в работе

---

### `html_dumps/` — Дампы HTML

**Назначение:** Сохраненные HTML страницы для анализа

**Содержимое:**
- `ad_search_*.html` — дампы страниц ad-search

**Использование:** Для анализа структуры страниц и отладки

---

### `screenshots/` — Скриншоты

**Назначение:** Скриншоты для документации (не в Git)

**Важно:** Не пушится в Git (в `.gitignore`)

---

## 🔄 Как добавить новый файл

### Код проекта → `src/`
```bash
# Новый модуль
src/new_module.py
```

### Тест → `tests/`
```bash
# Новый тест
tests/test_new_feature.py
```

### Утилита → `scripts/`
```bash
# Новый скрипт
scripts/new_utility.py
```

### Документация → `docs/`
```bash
# Новое руководство
docs/guides/NEW_GUIDE.md

# Новый справочник
docs/reference/NEW_REFERENCE.md
```

---

## 📋 Правила организации

1. **Код проекта** → только в `src/`
2. **Тесты** → только в `tests/`
3. **Утилиты** → только в `scripts/`
4. **Документация** → только в `docs/`
5. **Примеры** → только в `examples/`
6. **Секреты** → только в `config/` (и НЕ в Git!)
7. **Архив** → только в `archive/`
