## 💻 Скачивание и установка Cursor

### Шаг 1: Перейдите на сайт Cursor

Откройте в браузере: **https://cursor.sh/**

### Шаг 2: Скачайте Cursor

1. На главной странице нажмите кнопку **"Download"** или **"Download for Windows"**
2. Файл установки начнёт скачиваться (обычно это файл `Cursor-Setup.exe`)

### Шаг 3: Установите Cursor

1. Найдите скачанный файл в папке **"Загрузки"** (Downloads)
2. Дважды кликните по файлу `Cursor-Setup.exe`
3. Следуйте инструкциям установщика:
   - Нажмите **"Next"** (Далее)
   - Выберите папку для установки (можно оставить по умолчанию)
   - Нажмите **"Install"** (Установить)
   - Дождитесь завершения установки
   - Нажмите **"Finish"** (Готово)

### Шаг 4: Запустите Cursor

1. Cursor должен автоматически открыться после установки
2. Если нет — найдите его в меню "Пуск" и запустите
3. При первом запуске может потребоваться создать аккаунт или войти

**✅ Готово!** Cursor установлен и готов к работе.

## 🐍 Установка Python

### Шаг 1: Проверьте, установлен ли Python

1. Откройте **PowerShell** или **Командную строку** (нажмите `Win + R`, введите `cmd`, нажмите Enter)
2. Введите команду:
   ```bash
   python --version
   ```
3. Если видите версию (например, `Python 3.11.5`) — Python уже установлен, переходите к следующему разделу
4. Если видите ошибку `'python' is not recognized` — нужно установить Python

### Шаг 2: Скачайте Python

1. Откройте в браузере: **https://www.python.org/downloads/**
2. Нажмите большую жёлтую кнопку **"Download Python 3.x.x"** (где x.x.x — последняя версия)
3. Файл установки начнёт скачиваться

### Шаг 3: Установите Python

1. Найдите скачанный файл в папке **"Загрузки"** (обычно `python-3.x.x-amd64.exe`)
2. Дважды кликните по файлу
3. **ВАЖНО:** В самом начале установки поставьте галочку **"Add Python to PATH"** (Добавить Python в PATH)
4. Нажмите **"Install Now"** (Установить сейчас)
5. Дождитесь завершения установки
6. Нажмите **"Close"** (Закрыть)

### Шаг 4: Проверьте установку

1. Закройте и снова откройте **PowerShell** или **Командную строку**
2. Введите:
   ```bash
   python --version
   ```
3. Должна появиться версия Python (например, `Python 3.11.5`)

**✅ Готово!** Python установлен.

## 📦 Установка библиотек Python

### Шаг 1: Откройте терминал в Cursor

1. В Cursor нажмите **"Terminal"** (Терминал) в верхнем меню
2. Или используйте горячую клавишу: `Ctrl + ~` (Ctrl + тильда)
3. Внизу экрана откроется терминал

### Шаг 2: Установите библиотеки

В терминале выполните команду:

```bash
pip install -r requirements.txt
```

**Что делает эта команда:**
- `pip` — программа для установки библиотек Python
- `install` — команда установки
- `-r requirements.txt` — установить все библиотеки из файла requirements.txt

**Время выполнения:** 2-5 минут (зависит от скорости интернета)

**Что вы увидите:**
- Список устанавливаемых библиотек
- Прогресс установки
- В конце должно быть сообщение об успешной установке

### Шаг 3: Установите браузер для Playwright

После установки библиотек нужно установить браузер для автоматизации:

```bash
playwright install chromium
```

**Время выполнения:** 1-3 минуты

**✅ Готово!** Все библиотеки установлены.

## 📊 Настройка Google Sheets

Для работы проекта нужно настроить доступ к Google Таблицам.

### Шаг 1: Создайте проект в Google Cloud Console

1. Откройте в браузере: **https://console.cloud.google.com/**
2. Войдите в свой Google аккаунт
3. Нажмите на выпадающий список проектов вверху (рядом с "Google Cloud")
4. Нажмите **"New Project"** (Новый проект)
5. Введите название проекта: `ProductRadar` (или любое другое)
6. Нажмите **"Create"** (Создать)
7. Дождитесь создания проекта (5-10 секунд)

### Шаг 2: Включите Google Sheets API

1. В меню слева найдите **"APIs & Services"** (API и сервисы)
2. Нажмите **"Library"** (Библиотека)
3. В поиске введите: **"Google Sheets API"**
4. Нажмите на **"Google Sheets API"**
5. Нажмите кнопку **"Enable"** (Включить)
6. Дождитесь активации (5-10 секунд)

### Шаг 3: Создайте Service Account

1. В меню слева выберите **"APIs & Services"** → **"Credentials"** (Учётные данные)
2. Нажмите **"Create Credentials"** (Создать учётные данные)
3. Выберите **"Service Account"** (Сервисный аккаунт)
4. В поле **"Service account name"** введите: `productradar-sheets`
5. Нажмите **"Create and Continue"** (Создать и продолжить)
6. Нажмите **"Done"** (Готово)

### Шаг 4: Создайте ключ для Service Account

1. В списке Service Accounts найдите созданный аккаунт `productradar-sheets`
2. Кликните по нему
3. Перейдите на вкладку **"Keys"** (Ключи)
4. Нажмите **"Add Key"** (Добавить ключ) → **"Create new key"** (Создать новый ключ)
5. Выберите формат **"JSON"**
6. Нажмите **"Create"** (Создать)
7. Файл автоматически скачается (обычно в папку "Загрузки")

### Шаг 5: Сохраните ключ в проект

1. Найдите скачанный JSON файл в папке **"Загрузки"**
   - Обычно он называется что-то вроде: `productradar-sheets-xxxxx-xxxxx.json`
2. Переименуйте файл в: `google-credentials.json`
3. Скопируйте этот файл в папку `config` вашего проекта:
   - Путь должен быть: `ProductRadar/config/google-credentials.json`
4. В Cursor вы должны увидеть этот файл в папке `config/`

### Шаг 6: Предоставьте доступ к Google Таблице

1. Откройте файл `config/google-credentials.json` в Cursor
2. Найдите строку `"client_email"` (обычно на строке 5-6)
3. Скопируйте значение email (например: `productradar-sheets@xxxxx.iam.gserviceaccount.com`)
4. Откройте Google Таблицу: **https://docs.google.com/spreadsheets/d/1VJMixODvnIPBf7EjFoJ8XMH1lepycVlXREKQI7MVxWQ**
5. Нажмите кнопку **"Поделиться"** (Share) в правом верхнем углу
6. Вставьте скопированный email в поле
7. Выберите права доступа: **"Редактор"** (Editor)
8. Нажмите **"Отправить"** (Send)

**✅ Готово!** Google Sheets настроен.

## ⚙️ Настройка файла .env

Файл `.env` содержит секретные данные (пароли, ключи). Он уже должен быть в проекте, но если его нет — создайте его.

### Шаг 1: Создайте файл .env

1. В Cursor в корне проекта (там, где файл `requirements.txt`) создайте новый файл
2. Назовите его точно: `.env` (с точкой в начале!)
3. Если Cursor спрашивает, что это за файл — выберите "Text" или "Plain Text"

### Шаг 2: Заполните файл .env

Откройте файл `.env` и добавьте следующие строки:

```env
PIPIADS_EMAIL=aiagentforcosmobeauty@gmail.com
PIPIADS_PASSWORD=)ZRg8,tbOtsR>)U
GOOGLE_SHEETS_ID=1VJMixODvnIPBf7EjFoJ8XMH1lepycVlXREKQI7MVxWQ
```

**Важно:**
- Не ставьте пробелы вокруг знака `=`

## 🔧 Решение проблем

### Проблема 1: "python is not recognized"

**Решение:**
- Убедитесь, что Python установлен (см. раздел "Установка Python")
- При установке Python должна быть поставлена галочка "Add Python to PATH"
- Перезапустите терминал после установки Python

### Проблема 2: "pip is not recognized"

**Решение:**
- Убедитесь, что Python установлен правильно
- Попробуйте использовать `python -m pip` вместо просто `pip`:
  ```bash
  python -m pip install -r requirements.txt
  ```

### Проблема 3: Ошибка при установке библиотек

**Решение:**
- Проверьте подключение к интернету
- Попробуйте обновить pip:
  ```bash
  python -m pip install --upgrade pip
  ```
- Затем снова выполните:
  ```bash
  pip install -r requirements.txt
  ```

### Проблема 4: Ошибка "Google credentials файл не найден"

**Решение:**
- Убедитесь, что файл `google-credentials.json` находится в папке `config/`
- Проверьте, что файл называется именно `google-credentials.json` (без лишних символов)
- Убедитесь, что это JSON файл (можно открыть в Cursor и проверить формат)

### Проблема 5: Ошибка доступа к Google Таблице

**Решение:**
- Убедитесь, что вы предоставили доступ сервисному аккаунту (см. "Шаг 6" в разделе "Настройка Google Sheets")
- Проверьте, что email из `google-credentials.json` добавлен в таблицу с правами "Редактор"
- Убедитесь, что Google Sheets API включен в Google Cloud Console

### Проблема 6: Браузер не открывается / Playwright ошибки

**Решение:**
- Убедитесь, что вы выполнили команду:
  ```bash
  playwright install chromium
  ```
- Если ошибка повторяется, попробуйте:
  ```bash
  playwright install --force chromium
  ```

### Проблема 7: Cursor не открывает проект

**Решение:**
- Убедитесь, что вы открыли именно папку проекта (не отдельный файл)
- Попробуйте закрыть и снова открыть Cursor
- Убедитесь, что папка проекта существует и содержит файлы
