# 📥 Копирование саммари

## Автоматически
```bash
python download_summaries.py
```

## Вручную

1. https://github.com/EvgeniyRibakov/ProductRadar/tree/testing-logs/logs/summaries
2. Для каждого `.md` файла:
   - Открыть → "Raw" → скопировать
   - Создать файл в `logs/summaries/` с таким же именем
   - Вставить текст (UTF-8)
