### ОШИБКА 5: Старые видео берутся вместо свежих

**Проблема:** Фильтр pageQuery на странице товара не может правильно отфильтровать видео по дате. В результате берутся видео из марта, сентября, января вместо видео последних 7 дней.

**Решение:**

После получения видео со страницы товара через pageQuery, **ОБЯЗАТЕЛЬНО фильтровать в коде:**

```typescript
const today = new Date();
const sevenDaysAgo = new Date(today.getTime() - 7 * 24 * 60 * 60 * 1000);

const filteredVideos = videos.filter(video => {
  const videoDate = parseVideoDate(video.firstSeen);
  const isWithinSevenDays = videoDate && videoDate >= sevenDaysAgo;
  return isWithinSevenDays;
});
```

Использовать функцию `parseVideoDate` для парсинга дат в формате "Oct 27 2025":

```typescript
function parseVideoDate(dateString: string): Date | null {
  if (!dateString || dateString === "N/A") {
    return null;
  }
  const months: { [key: string]: number } = {
    "Jan": 0, "Feb": 1, "Mar": 2, "Apr": 3, "May": 4, "Jun": 5,
    "Jul": 6, "Aug": 7, "Sep": 8, "Oct": 9, "Nov": 10, "Dec": 11
  };
  const parts = dateString.trim().split(" ");
  if (parts.length !== 3) {
    return null;
  }
  const monthStr = parts[0];
  const dayStr = parts[1];
  const yearStr = parts[2];
  const month = months[monthStr];
  const day = parseInt(dayStr, 10);
  const year = parseInt(yearStr, 10);
  if (month === undefined || isNaN(day) || isNaN(year)) {
    return null;
  }
  return new Date(year, month, day);
}
```

После фильтрации использовать `filteredVideos` вместо `videos` в основном цикле

### ОШИБКА 6: Неправильное извлечение impressions из ad-search страницы

**Проблема:** pageQuery путал "Impressions" (Показы) с "Likes" (Нравится) на странице ad-search, возвращая маленькие числа (168, 47, 28) вместо реальных (101300, 13200, 15100).

**Решение:**
- В pageQuery для ad-search страницы использовать очень специфичный prompt:

- **ОБЯЗАТЕЛЬНО упомянуть**, что это "Показы", а не "Нравится"
- Указать, что это большое число вроде "15.1K", а не маленькое

### ОШИБКА 7: TypeScript ошибка типа AirtopSession

**Решение:** Использовать `session: any` вместо конкретного типа
