# 🤖 План Telegram бота

## Функции

- **🔄 Запустить парсер** — выбор количества товаров (3/5/10/25)
- **📊 Просмотр саммари** — список последних итераций
- **⚙️ Настройки** — количество товаров, impressions, дни, режим браузера
- **📈 Статус** — текущее состояние, последняя итерация
- **🛑 Остановить парсер**

---

## Технические решения

- **Запуск парсера:** `subprocess.Popen()` — отдельный процесс
- **Хранение настроек:** `config/bot_settings.json`
- **Секреты:** `.env` (токен, user_id)
- **Саммари:** чтение из `logs/summaries/iteration_*.md`
- **Авторизация:** проверка `user_id` из `.env`

---

## Структура

```
src/
├── telegram_bot.py      # Основной бот
├── parser_runner.py      # Запуск парсера
├── summary_manager.py    # Чтение саммари
└── bot_config.py         # Конфигурация

config/
└── bot_settings.json     # Настройки парсера

run_telegram_bot.py       # Точка входа
```
